4. Supports: where each value came from

Engineering values: where each came from

Process block, class, rating, material, wall, corrosion, insulation, bore and rigid weight: every value the stage changed, with the step that set it and its source (Run popup, line list, piping class, branch name, override, default, input XML).

5. Property transfer under locks

Open the Enriched XML a transfer wrote to and its transfer receipt. The transferred values are locked; the supports and engineering stage then runs (with the staged JSON, config and material rows chosen in section 4) and every value it was stopped from changing is listed. The final XML keeps the protection note that today's step 10 reads.
