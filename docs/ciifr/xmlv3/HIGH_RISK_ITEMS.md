# XMLv3 high-risk items and boundaries

This register separates implemented guards from unresolved engineering source work. Passing the supported real fixture is not universal format or native acceptance. Product source is under `prototypes/ciifr-xmlv3/`; the held XMLv2 engine/profile remain unchanged.

| Risk | Implemented boundary | Remaining work / falsifier |
|---|---|---|
| Original-file replay masquerading as conversion | Writer consumes typed XML storage and validated references, without a raw original payload. Separate-process check denies opens/network after imports. | Any required original/sidecar/cache or ignored represented edit fails fidelity. |
| Silent dependency drift | Exact engine/profile SHA-256 checked at process startup, with isolated profile import. | Pin verification is startup-scoped, not a filesystem watcher. A changed package needs a new explicit source decision and regression. |
| CONTROL count corruption | Inherited record/count validation; structural digest protects count fields and pointer/node/material identities. | Count-changing operations are unsupported. Qualify logical units and complete create/delete/reindex transitions before adding them. Native trailing-field/padding admissibility remains E1 `F3_SOURCE_BLOCKED`. |
| MISC shifts with data | Current profile checks material cardinality, packed rows and four execution rows. Material field references remain positional by element storage. | NOZZLES/HANGERS branches, defaults, GUIDs, omission/allocation rules, execution meanings and all structural material reindexing need source/native evidence. Do not generalize H=0/N=0 receipts. |
| Duplicate engineering authority | Views contain references to one stored field; regenerated contract rejects stale, extra and duplicated graph nodes. | A Line Number grouping is not physical connectedness. Future consumers must retain model scope and qualified ownership. |
| Shared Node Name contradictions | Keep every endpoint/name occurrence; expose conflicting aliases and shared name fields across distinct nodes. | Issues are review evidence, not an accepted mapping or permission to write a logical-node property to every occurrence. More auxiliary/end semantics require qualification. |
| Numeric/lexical damage | Source lexemes/layout retained; explicit edits must fit exactly; nonpositive diameter edits restricted by this API's policy. | Signed-zero/exponent/precision and other property families need their own retained or new independent checks. No rounding, clamping or invented unit transforms. |
| Reconstructed output published partially or over an original | Validate before publication; complete/fsynced temporary file published exclusively (Windows rename, other platforms hard link); existing input/destination protected. | Fault injection is labeled SIMULATED. Full crash/power-loss durability and all filesystems are NOT_RUN; unsupported publication fails closed. |
| Unsafe or oversized XML | DTD/entities screened before parsing; strict schema. EOF-aware CLI XML reader consumes at most150000001 bytes before parsing, continues after short reads and retains exact size/error behavior. | Byte cap is not a total-memory/RSS, deadline or atomic-snapshot guarantee. CII intake budget is unchanged. Direct APIs receive caller-materialized bytes; future services/browser intake still need their own body limits. |
| Consistency digest mistaken for permission | Structural digest is explicitly non-authenticating; regenerated references bind views to current storage. | Someone intentionally editing XML can recompute a digest. Source authority, cross-model mapping and engineering acceptance require their actual controls. |
| Source profile mistaken for full v14 | Unsupported populated grammars fail closed. Byte equality uses independently captured original, not native-app assumptions. | Add observed real dialects/sections one bounded grammar at a time; retain failed cases and source provenance. |

The first expansion should address a demonstrated failure or a new authoritative source. Repeating the prior unsuccessful F3 documentation search without a new source/access route is not a useful task. Native importer contrasts require their own actual authorization and installed/runtime custody.

No item in this register authorizes modifying frozen P2/P2.1, held XMLv2, Geometry workstreams, Writer integration, property transfer, merge or deployment.
