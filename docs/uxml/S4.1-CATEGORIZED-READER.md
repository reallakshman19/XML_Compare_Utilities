# UXML S4.1 — Categorized InputXML original-bound read-only reader

## Authority and limits

Owner decision: **Option A — original-bound unique matching**. Source base: XCU main `578517545415c8ae371c9d21e54fcfbae8e44c3f` after Owner accepted S4.0.
S4.1 is READ_ONLY. It never writes, reverse-converts, patches, exports corrected XML,
joins connections, changes CLOS, or changes policy/tolerances. S4.2 is separate.

Canonical entry point:
`mapCategorizedInputXmlToUxml(categorizedText, {originalBytes?,originalInputXml?,fileSha256?})`
from `uxml/UxmlCategorizedInputXmlSchemaMapper.js`. The docs copy is kept
byte-for-byte in sync. This does not change the S3 reader, its mapping or the
S4.0 compatibility converter.

### Source-binding rule

With the original InputXML, the caller **must supply a measured SHA-256** of the
original byte sequence; the reader independently recomputes SHA-256 from
`originalBytes` (preferred, exact bytes) or UTF-8 encoded `originalInputXml` text.
The latter is a UTF-8 text contract, not proof of arbitrary disk-encoding identity.
Invalid UTF-8 bytes refuse; never normalize BOM or CRLF for the digest.
When both originalBytes and originalInputXml are supplied, their exact UTF-8
byte sequences must agree; otherwise the reader refuses rather than
arbitrarily selecting one representation.

The reader extracts physical PIPINGELEMENT records in original source order
using the same conservative extraction seam as the converter, and uses the
S3 identity formula:

`E{zeroBasedPhysicalOrdinal}:F{encodeURIComponent(FROM_NODE)}:T{encodeURIComponent(TO_NODE)}`

For every Categorized Line/Element, the complete **trimmed OriginalElement
snapshot**, normalized FROM_NODE/TO_NODE, elementKey and owning Line id must
jointly identify exactly **one** original physical record. One-to-one applies
**over the entire document**: no original can be claimed twice and none may
remain unmatched. Categorized presentation order is irrelevant: A/B/A physical
records can become A/A/B groups while keeping the original E0/E2/E1 keys.

**Known limit:** When the ORIGINAL has byte-identical duplicate PIPINGELEMENT
records, multiple physical ordinals fit one Categorized element. S4.1 **REFUSES
instead of guessing** an ordinal. Incomplete last source records (the public
PLB314 InputXML sample contains an unclosed last PIPINGELEMENT) also refuse
ORIGINAL_STRUCTURE rather than throwing or returning partial UXML.
Every original PIPINGELEMENT must have its own explicit closing
`</PIPINGELEMENT>` or a genuinely self-closing `<PIPINGELEMENT .../>`
opening. A self-closing CHILD (for example `<RIGID WEIGHT="1"/>`)
is never evidence that its PIPINGELEMENT parent closed. The sum of
PIPINGELEMENT closing tags and self-closing PIPINGELEMENT openings must
equal physical PIPINGELEMENT openings; inconsistent source structure
refuses before any sourceRefs are issued.
No provenance sidecar is added; the converter
is not modified to invent physical ordinals.

The bound-original path **runs unmodified**
`mapCaesarInputXmlToUxmlStrict(original,{fileSha256:measured})`
before UXML construction. An exception/refusal from strict S3 fails closed
as `CATEGORIZED_ORIGINAL_S3_REFUSED`, with only the named S3 error code in
`s3Code` (no UXML). The complete S4.1 physical-record key set must equal
the strict S3 component sourceRef key set exactly, including cardinality
and uniqueness. If these disagree, it refuses `CATEGORIZED_S3_KEY_MISMATCH`.
This also catches comment-hidden PIPINGELEMENT records: S4.1 never binds
any original that S3 would refuse. Source records stay read-only.
The source-bound UXML components carry
`sourceRefs: [{format:"INPUT_XML",fileSha256:<measured original>,recordKey:<S3 key>,...}]`.
Each component retains a **read-only** OriginalElement snapshot, uncommitted
Categorized projection and original source attributes. Geometry stays
`NOT_INFERRED`, normalized type `UNKNOWN`: S4.1 is not
an alternate topology solver. The original source text is carried as source
evidence; no reconstructed XML is ever a patch input.

### Derived/projection rules

Line/Element/derived blocks are **reviewable evidence** only. To detect
unreviewed changes, the reader independently generates the expected
Categorized projection from the verified original via the **forward converter**
and compares each Element's non-OriginalElement projection and its Line's
non-Element projection. It never calls the reverse converter. A differing
Element projection refuses unless it carries:

`<ReviewMarker kind="DERIVED_DIFFERENCE" disposition="REVIEW_ONLY"/>`

This is solely a local review-only marker contract, and it is recognized
**only outside OriginalElement CDATA**; source snapshot text containing the
same markup is never treated as an approval. Its presence yields
`REVIEW_REQUIRED`, `sourceEquivalent:false`, `exportAllowed:false`;
it cannot grant write/apply authority. Differing line-level projections always
refuse. Repeated literal RESTRAINT/DISPLACEMENTS/FORCESMOMENTS stanzas across
different original records and unknown uncaptured original header/sections
refuse rather than trusting the compatibility reverse converter's global
lexical deduplication. Known original root/PIPINGMODEL attributes are retained
in the original source witness; non-carried extra sections are not silently
accepted. Root/CAESARII and PIPINGMODEL attributes (for example JOBNAME)
are **retained as original InputXML source witnesses**, not used as
Categorized projection mismatch refusals. An unknown standalone section
not carried in those witnesses still refuses.

**Enriched** means marker presence (PipingClass, Rating, DTXR_POS/PS,
MaterialNumber/Name, LINE_ID, FROM_NAME, TO_NAME), not another source format.

### Refusals (no UXML output)

Every refusal returns `{ok:false,status:"REFUSED",code,uxml:null,exportAllowed:false}`.

| Code | Guard |
|---|---|
| CATEGORIZED_INVALID_DOCUMENT | Missing/invalid v3 root or malformed Line/Element/OriginalElement evidence |
| CATEGORIZED_ORIGINAL_FILE_SHA_REQUIRED | No valid SHA supplied with original |
| CATEGORIZED_ORIGINAL_FILE_SHA_MISMATCH | Independently measured original digest differs |
| CATEGORIZED_ORIGINAL_ENCODING_UNSUPPORTED | Supplied bytes cannot be decoded as strict UTF-8 |
| CATEGORIZED_ORIGINAL_INPUT_BYTES_TEXT_CONFLICT | Both original byte and text inputs provided but their UTF-8 sequences disagree |
| CATEGORIZED_ORIGINAL_STRUCTURE_UNSUPPORTED | Unsupported or incomplete physical records, unclosed parent or closure-count mismatch |
| CATEGORIZED_ORIGINAL_S3_REFUSED | Unmodified strict S3 reader threw/refused the same original; `s3Code` carries the named S3 error code |
| CATEGORIZED_S3_KEY_MISMATCH | Bound S4.1 recordKey set differs in identity/cardinality/uniqueness from strict S3 |
| CATEGORIZED_RECORD_KEY_MISSING | Missing categorized FROM/TO/elementKey |
| CATEGORIZED_ORIGINAL_RECORD_NO_MATCH | No exact source record fits snapshot and identities |
| CATEGORIZED_ORIGINAL_RECORD_AMBIGUOUS | Multiple physical records fit, including byte-identical duplicates |
| CATEGORIZED_ORIGINAL_RECORD_CLAIMED_TWICE | Two categorized records claim the same original |
| CATEGORIZED_ORIGINAL_RECORD_UNCLAIMED | At least one original record not represented |
| CATEGORIZED_DERIVED_DIFFERENCE_UNREVIEWED | Projection changes without review marker, or altered line projection |
| CATEGORIZED_DUPLICATED_EXTERNAL_BLOCK | Repeated raw external restraint/displacement/force stanza across records |
| CATEGORIZED_UNKNOWN_SOURCE_SECTION | Unknown non-carried header/section outside original element records |
| CATEGORIZED_UXML_VALIDATION_REJECTED | Shared UxmlValidationGate returned ready:false on source-bound output; no UXML is returned |

No original supplied: `{ok:true,status:"NOT_SOURCE_EQUIVALENT",sourceEquivalent:false,exportAllowed:false}`
with reviewable evidence and a UXML skeleton **without sourceRef-bearing
components**. OriginalDocument embedded in Categorized and recoverable CDATA
do **not** change this state. The shared `UxmlValidationGate` always runs
and its report is attached even when source identity is absent; this
no-original evidence-only path stays NOT_SOURCE_EQUIVALENT. On the
**source-bound** path a failing shared gate causes
`CATEGORIZED_UXML_VALIDATION_REJECTED`, with `uxml:null` (not a
partly accepted document). A passing gate still cannot enable Apply:
source-bound returns remain `exportAllowed:false`.
