## API

`await patchOriginalFromCategorized(originalText,baselineCategorized,editedCategorized,{fileSha256})`

Inputs:
- `originalText`: exact UTF-8 original text, including any BOM and
  literal LF/CRLF. This slice accepts text, not arbitrary legacy encodings.
- `baselineCategorized`: **byte-for-byte exact**
  `inputXmlToCategorizedInputXml(originalText)` using the unchanged S4.0
  forward converter and its default sourceName.
- `editedCategorized`: S4.0-format categorized document whose
  `OriginalElement` CDATA has only intended existing attribute-value
  substitutions. The forward-converter-derived blocks must be kept
  **consistent** with those edits (for example, by updating derived
  projections to the S4.0 output of the proposed edited source).
  Editing a derived or Line block **alone** is not an edit instruction.
  No element added, removed or reordered, no changed Line owner or
  FROM_NODE/TO_NODE source identity. This slice does not implement a
  projection-to-source field mapper.
- `fileSha256`: SHA-256 of the exact original UTF-8 byte stream, not
  a mutable claimed digest.

Returns only:
- **success:** `{ok:true,bytes:Uint8Array,changes:[{recordKey,field,old,new,byteRange:{start,end}}],parity:'EQUAL'}`.
  Byte ranges are **half-open offsets into original UTF-8 bytes**;
  a varying-length replacement never changes their original meaning.
  A no-edit request returns an exact copy of original bytes and
  `changes:[]`, subject to the same gates.
- **refusal:** `{ok:false,code,bytes:null}`. No partial output and
  no fallback writer.

## Implementation gates in fixed order

1. Validate input types and independently hash original exact UTF-8 bytes.
2. Require baseline Categorized text to equal S4.0(original) **exactly**;
   never accept a stale or forged baseline. Run S4.1 baseline against
   original SHA, requiring `SOURCE_BOUND_READ_ONLY` and one-to-one
   sourceRefs; read-only `exportAllowed:false` remains.
3. Run the shared structural scanner on the original. Each physical
   `PIPINGELEMENT` record has a zero-based ordinal, an exact character
   `start` and exact `raw` slice. Reject offset mismatch between
   that recorded source and original text.
4. Pair `Element` items in categorized order against baseline S4.1
   sourceRefs, requiring same Line, identity attributes, cardinality and
   presentation order. Reorder/add/remove or changed FROM_NODE/TO_NODE,
   LINE_ID or PIPELINE-REFERENCE refuses.
5. Lex each source row and edited OriginalElement with quote-aware
   attribute-value extraction. Mask attribute values and compare the
   entire remaining row to enforce identical markup, attribute
   names/order/quotes, child structure and non-attribute text. Changes
   are permitted only to attributes on the PIPINGELEMENT or its
   **direct child stanza**. Nested-child edits return
   `S42_NESTED_ATTRIBUTE_EDIT_REFUSED`.
   Existing XML attribute values may use quote-specific
   `&amp;`, `&lt;`, `&quot;` and `&apos;` escapes; unsafe or
   noncanonical changed entities refuse. **TAB, CR and LF in a changed
   value are refused** as `S42_ATTRIBUTE_VALUE_UNSAFE`,
   including `&#9;`, `&#10;` and `&#13;` numeric character
   references; they are not silently normalized or re-encoded.
6. Globally harvested external stanzas (RESTRAINT, DISPLACEMENTS,
   FORCESMOMENTS, ALLOWABLESTRESS and SIF) have immutable S4.0
   **control and node-reference attributes**. S4.0's
   `CategorizedInputXmlConverter.js:23` exact control list is
   `NUM, NUMBER, SIF_NUM, DISP_NUM, FORCMNT_NUM, NODE, NODE_NUM, NODE1, NODE2, NODE3, CNODE`.
   Slice 1 also conservatively protects
   `GLOBAL_COORD_BASIS_NODE, FROM_NODE, TO_NODE` on external
   stanzas. Any such edit returns
   `S42_RECORD_IDENTITY_EDITED`, even when the proposed
   NODE moves to another occupied node or an unset sentinel.
   For other external value edits, lexRow indexes **actual opening
   stanzas**, skipping comments/CDATA. Owner identity is taken from
   the **same stanza**, not from a count of attributes or a regex
   list: NODE for RESTRAINT/SIF and NODE_NUM for
   DISPLACEMENTS/FORCESMOMENTS. Node numbers are normalized exactly
   as S4.0 groups them (20 and 20.0 are equal). The proposed edit
   must have a concrete **unique owner across every real stanza**
   both before and after the edit. A duplicate owner across rows
   returns `S42_SHARED_EXTERNAL_EDIT_REFUSED`.
   ALLOWABLESTRESS and other stanzas without individually verifiable
   node owners are review-only. Non-record UNITS remains immutable;
   S4.0 may carry an unchanged trailing UNITS witness in the final
   self-closing record snapshot, but it is never a physical row.
7. Convert each verified character span into **UTF-8 byte offsets**,
   verify old raw attribute bytes at that range, prove ranges are
   increasing/non-overlapping, and replace from **right to left** in
   the original byte array. Header, BOM, original EOL/spacing, attribute
   order/quote, root, comments, PIs, UNITS, untouched records, and all
   unrelated bytes remain unchanged.
8. **Before returning any bytes**, run strict S3 on patched UTF-8 text;
   require the original exact physical ordinal recordKey sequence to
   match. Require S4.0(patched) == editedCategorized **exactly**
   (stronger than per-field equivalence), then S4.1(editedCategorized,
   patched, new SHA) must bind, with the same recordKey sequence.
   Every failure returns named refusal `bytes:null`.

No reverse converter use. No topology/snapshot reassembly, undo,
writing to disk, or UI apply support in slice 1.

## Named refusal taxonomy

| Code | Meaning |
|---|---|
| S42_INVALID_INPUT | Invalid arguments |
| S42_ORIGINAL_SHA_MISMATCH | Original bytes differ from pinned SHA |
| S42_BASELINE_NOT_S40_EXACT | Categorized baseline not exact forward output |
| S42_UNBOUND_RECORD | Baseline S4.1 cannot bind one-to-one or sourceRef incomplete |
| S42_ELEMENT_ADDED_REMOVED_OR_MARKUP_EDITED | Source row structure, attribute inventory, non-attr text, added/deleted element or stanza |
| S42_NESTED_ATTRIBUTE_EDIT_REFUSED | Edit below a direct child (nested stanza) is forbidden in slice 1 |
| S42_ELEMENT_REORDERED | Categorized element order changed |
| S42_RECORD_IDENTITY_EDITED | Source/categorized identity changed, or any S4.0 control/node-reference attribute on an external stanza edited |
| ~~S42_DERIVED_OR_LINE_PROJECTION_EDITED~~ (RETIRED in B7) | This old unused code was never emitted by slice 2; use S42_UNMAPPED_OR_DERIVED_PROJECTION_EDIT or S42_S40_PROJECTION_MISMATCH instead. |
| S42_SHARED_EXTERNAL_EDIT_REFUSED | External stanza has no verified unique numeric-normalized node owner before and after edit |
| S42_UNITS_EDIT_REFUSED | Converter-carried nonrecord UNITS suffix edited |
| S42_ATTRIBUTE_VALUE_UNSAFE | Invalid/noncanonical entity or changed value; TAB, CR, LF including numeric character references |
| S42_SOURCE_OFFSET_NOT_EXACT | Source slice/byte offset, range overlap or prior bytes mismatch |
| S42_PARITY_FAILED | Patched S3 key sequence or patched S4.1 source-bound gate failed |

## Independent review 80/100 — narrow final repair round R2

The fresh independent review at the previous R1 head
`1d24df6c4a4732b130b2a7389251cd78991526e4`
scored **80/100 (18/15/14/16/17), REPAIR/HOLD** despite
42/42 source tests and 28/28 LF plus CRLF mutation kills.
The remaining blocking class was a **semantic disagreement**:
S4.0's compatibility converter uses its *own loose regex*
(`splitLooseBlocks`, `nodeBlocks`, `attrsOf`,
`activeNodeBlock`, `activeSifBlock`) on the entire
raw InputXML, so comments, CDATA and nested tags may be harvested.
The old S4.2 XML-aware `lexRow` intentionally ignored
those same spans. That mismatch allowed an otherwise unique-looking
external edit to affect a globally shared S4.0 projection.

**R2 belt-and-braces gate:**
- S4.2 imports the **exact existing S4.0** `_test` functions.
  It does not fork or edit the converter. Original and patched byte
  streams are scanned separately with S4.0's own
  `splitLooseBlocks`, active block filter and exact-case
  `attrsOf` grouping; for SIF the check uses the specific
  PIPINGELEMENT body.
- Require exactly **one active S4.0 block of the same tag and
  numerically normalized owner** before and after the edit, and
  require its **exact raw block text** to equal the actual stanza
  that contains the edited attribute. If the converter would harvest
  a second block, or sees a different block than the editor, return
  `S42_SHARED_EXTERNAL_EDIT_REFUSED` with `bytes:null`.
- **Fail closed** for any external value edit when the original or
  proposed bytes have a comment/CDATA containing an external tag
  token, a real external tag nested below an element's direct
  children, or mixed-case duplicate names on the edited stanza.
  This also catches `node="99" NODE="20"` and
  S4.0's last-wins exact-case ownership.
- **Low-priority XML correction:** a literal `>` is
  legal inside a quoted XML attribute value. It is accepted and
  preserved byte-for-byte in the written value, provided S3/S4.0/S4.1
  final parity still holds. It is not forcibly rewritten to
  `&gt;`. No other edit class is expanded.
- Adversarial source/test evidence includes comment-hidden and
  CDATA-hidden RESTRAINT, nested RESTRAINT within BEND,
  nested DISPLACEMENTS within RIGID, mixed-case node/NODE,
  SIF hidden by comment in the same PIPINGELEMENT, post-edit
  inactive external block, and literal `>` acceptance.
  Assertions use S4.0's own exported `nodeBlocks`,
  `splitLooseBlocks`, `attrsOf` and activity
  predicates. Each class has disposable isolated original-red
  mutations in LF and simulated CRLF.

### Three edit forms and parity

1. **Projection-only:** compare the Categorized edit to the pinned
   S4.0 baseline and select only directly mapped leaf changes.
   Bind every target to the existing SHA-verified physical record
   through S4.1 and the shared source scanner. Change only the
   existing root attribute's value in an in-memory candidate.
   Require unchanged S4.0(candidate) to echo the **same text**
   the user typed, without hidden rounding or number formatting.
   Generate the fully canonical edited Categorized, then delegate
   to slice 1's existing byte-range writer, strict S3, original
   recordKey/ordinal, exact S4.0 and final S4.1 parity gates.
2. **Snapshot-only with stale visible projection:** continues to
   refuse S42_S40_PROJECTION_MISMATCH, bytes:null.
3. **Consistent snapshot plus projection:** original slice 1's
   authorization remains in place, including fully canonical
   edits where a formerly unset field becomes present. Mixed
   mismatched snapshots refuse. An unmatched derived/unknown tag
   refuses S42_UNMAPPED_OR_DERIVED_PROJECTION_EDIT.
   Noncanonical output text or unavoidable reformatting refuses
   S42_PROJECTION_VALUE_NOT_EXACT. A typed 123.456 is written
   and echoed as 123.456, **not** 123.456000.

**Authority rule:** A line displays the first nonempty, non-sentinel
(\`-1.0101\`) attribute value in that Line. For a changed visible leaf,
verify the S4.1 source reference for each corresponding physical row; collect
all explicit non-sentinel holders; require each holder to have the exact same
old S4.0 text echo; patch **each** holder at its original byte-value range.
Do not materialize missing values or overwrite sentinels. Other lines and
unrelated attributes are immutable. Source values that genuinely disagree
refuse \`S42_LINE_DERIVED_OR_DISAGREEING_VALUES\`, no bytes. S4.0 of the
candidate must exactly echo every typed leaf and the existing slice-1 S3,
S4.0 and S4.1 parity gates must all pass before \`ok:true\`, \`parity:EQUAL\`.

**No source NAME invention:** When S4.0 displays the element-key fallback
for omitted \`PIPINGELEMENT@NAME\`, return
\`S42_SOURCE_ATTRIBUTE_OMITTED_OR_DERIVED\` (with element row and tag).
Existing \`NAME\` values are editable; identity node attributes and element
order remain immutable. \`DELTA_Y\` edits are source-bound like other deltas,
but conflicts with source-anchored S3 graph invariants refuse
\`S42_SOURCE_GRAPH_CONFLICT\`, not generic numerical reformatting.
