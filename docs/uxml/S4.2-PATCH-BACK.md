## API

`await patchOriginalFromCategorized(originalText,baselineCategorized,editedCategorized,{fileSha256})`

Inputs:
- `originalText`: exact UTF-8 original text, including any BOM and
  literal LF/CRLF. This slice accepts text, not arbitrary legacy encodings.
- `baselineCategorized`: **byte-for-byte exact**
  `inputXmlToCategorizedInputXml(originalText)` using the unchanged S4.0
  forward converter and its default sourceName.
- `editedCategorized`: S4.0-format categorized document whose
  `OriginalElement` CDATA has only intended existing attribute-value
  substitutions. The forward-converter-derived blocks must be kept
  **consistent** with those edits (for example, by updating derived
  projections to the S4.0 output of the proposed edited source).
  Editing a derived or Line block **alone** is not an edit instruction.
  No element added, removed or reordered, no changed Line owner or
  FROM_NODE/TO_NODE source identity. This slice does not implement a
  projection-to-source field mapper.
- `fileSha256`: SHA-256 of the exact original UTF-8 byte stream, not
  a mutable claimed digest.

Returns only:
- **success:** `{ok:true,bytes:Uint8Array,changes:[{recordKey,field,old,new,byteRange:{start,end}}],parity:'EQUAL'}`.
  Byte ranges are **half-open offsets into original UTF-8 bytes**;
  a varying-length replacement never changes their original meaning.
  A no-edit request returns an exact copy of original bytes and
  `changes:[]`, subject to the same gates.
- **refusal:** `{ok:false,code,bytes:null}`. No partial output and
  no fallback writer.

## Implementation gates in fixed order

1. Validate input types and independently hash original exact UTF-8 bytes.
2. Require baseline Categorized text to equal S4.0(original) **exactly**;
   never accept a stale or forged baseline. Run S4.1 baseline against
   original SHA, requiring `SOURCE_BOUND_READ_ONLY` and one-to-one
   sourceRefs; read-only `exportAllowed:false` remains.
3. Run the shared structural scanner on the original. Each physical
   `PIPINGELEMENT` record has a zero-based ordinal, an exact character
   `start` and exact `raw` slice. Reject offset mismatch between
   that recorded source and original text.
4. Pair `Element` items in categorized order against baseline S4.1
   sourceRefs, requiring same Line, identity attributes, cardinality and
   presentation order. Reorder/add/remove or changed FROM_NODE/TO_NODE,
   LINE_ID or PIPELINE-REFERENCE refuses.
5. Lex each source row and edited OriginalElement with quote-aware
   attribute-value extraction. **Mask attribute values** and compare
   the entire remaining row to enforce identical markup, attribute
   names/order/quotes, child structure and non-attribute text. Changes
   are permitted only to attributes on the `PIPINGELEMENT` or its
   **direct child stanza**; nested child edits refuse. Existing XML
   attribute values may use quote-specific `&amp;`, `&lt;`,
   `&quot;`, `&apos;` escape sequences; unsafe/raw or
   noncanonical changed entities refuse.
6. A direct child that participates in globally harvested external
   evidence (RESTRAINT, DISPLACEMENTS, FORCESMOMENTS, ALLOWABLESTRESS,
   SIF) must have a unique concrete node owner among original rows;
   otherwise refuse for manual engineering review. Never allow edits
   within a non-record UNITS sibling. The unchanged S4.0 converter may
   carry trailing UNITS text in the final self-closing record's
   OriginalElement snapshot: require that suffix to remain exactly
   unchanged. It does not become a source record.
7. Convert each verified character span into **UTF-8 byte offsets**,
   verify old raw attribute bytes at that range, prove ranges are
   increasing/non-overlapping, and replace from **right to left** in
   the original byte array. Header, BOM, original EOL/spacing, attribute
   order/quote, root, comments, PIs, UNITS, untouched records, and all
   unrelated bytes remain unchanged.
8. **Before returning any bytes**, run strict S3 on patched UTF-8 text;
   require the original exact physical ordinal recordKey sequence to
   match. Require S4.0(patched) == editedCategorized **exactly**
   (stronger than per-field equivalence), then S4.1(editedCategorized,
   patched, new SHA) must bind, with the same recordKey sequence.
   Every failure returns named refusal `bytes:null`.

No reverse converter use. No topology/snapshot reassembly, undo,
writing to disk, or UI apply support in slice 1.

## Named refusal taxonomy

| Code | Meaning |
|---|---|
| S42_INVALID_INPUT | Invalid arguments |
| S42_ORIGINAL_SHA_MISMATCH | Original bytes differ from pinned SHA |
| S42_BASELINE_NOT_S40_EXACT | Categorized baseline not exact forward output |
| S42_UNBOUND_RECORD | Baseline S4.1 cannot bind one-to-one or sourceRef incomplete |
| S42_ELEMENT_ADDED_REMOVED_OR_MARKUP_EDITED | Source row structure, attribute inventory, non-attr text, added/deleted element or stanza |
| S42_ELEMENT_REORDERED | Categorized element order changed |
| S42_RECORD_IDENTITY_EDITED | FROM_NODE/TO_NODE/LINE_ID/PIPELINE-REFERENCE or categorized identity changed |
| S42_DERIVED_OR_LINE_PROJECTION_EDITED | Edited projected or Line content inconsistent with S4.0(patched) |
| S42_SHARED_EXTERNAL_EDIT_REFUSED | External direct child has ambiguous/global owner |
| S42_UNITS_EDIT_REFUSED | Converter-carried nonrecord UNITS suffix edited |
| S42_ATTRIBUTE_VALUE_UNSAFE | Invalid XML attribute entity or changed value |
| S42_SOURCE_OFFSET_NOT_EXACT | Source slice/byte offset, range overlap or prior bytes mismatch |
| S42_PARITY_FAILED | Patched S3 key sequence or patched S4.1 source-bound gate failed |

## S4.1 review preconditions folded into this slice

`UxmlCategorizedInputXmlSchemaMapper.js` and its exact mirror now
reject **any harvested tag** (RESTRAINT/DISPLACEMENTS/FORCESMOMENTS/
ALLOWABLESTRESS/BEND/RIGID/FLANGES/SIF) appearing inside an otherwise
legitimate UNITS model sibling, using named
`CATEGORIZED_UNKNOWN_SOURCE_SECTION` and `uxml:null`. Recognized
UNITS section stripping uses `<UNITS(?=[\\s/>])`; a sibling
`<UNITS-X/>` is not recognized and refuses. Both guards have
synthetic tests and CRLF-safe isolated mutants. The shared scanner's
previous stale `recordsOnlyModel` comments were corrected without
altering its runtime code, and its source/docs mirror stays identical.
