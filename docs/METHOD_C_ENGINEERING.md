**Authority:** `CII-METHOD-C@1.0.0`, label_sha `18d91c9`, plan `V36-108-PLAN-01`, parent issue #108; draft PR #118. Geometry **REVIEW_ONLY**: no physical identity qualification, Writer2 Apply, benchmark-specific production mapping, original CII mutation or original Method A/B alteration.

## Modules and data flow

1. `cii-workspace-method-c-original-geometry.js`: `buildOriginalGraphFromBytes({bytes, member, expectedSha256, cryptoRef})` derives SHA-256 from original `Uint8Array` with WebCrypto; rejects mismatched hash, native CONTROL cardinality, bad 15-row signed ELEMENTS, pointer/COORDS/UNITS corruption and inconsistent signed graph cycles. Returns physical NODEs, raw member/hash, incident original ELEMENT witness, 3D signed coordinates, seeded vs relative frames and disconnected components. No derived golden fixture is ever required.
2. `cii-workspace-method-c-registration.js`: `registerMethodC(source,target,anchors,options)` calculates `pT=R·pS+t` with rigid `det R=+1`, fixed scale=1. One anchor has unknown rotation, two equal-separation anchors unknown axial twist, 3+ independently admissible non-collinear anchors solve least-squares Horn/Jacobi pose. Contradictions and residuals remain inspectable.
3. `cii-workspace-method-c-candidates.js`: `findMethodCCandidates(source,target,pose,{x:100,y:100,z:100})` spatially indexes physical TARGET NODEs in *only the registered component*. Inclusive independent XYZ tolerances; preserve alternatives, TARGET collisions, nearest physical NODE outside the box and original TARGET ELEMENT-only projection. Never mint a fake physical NODE; no row authorizes Writer2.
4. `cii-workspace-method-c-svg.js`: `methodCSvgScene({source,target,transform,candidates,projection,selectedSource,scope,...})` draws original piping centerlines, original ELEMENT witness tooltips, physical NODE markers and segment-only projection. XZ/YZ/XY use common real millimetre scale. ISO is conspicuously non-metric. XML-escape all raw labels and original witnesses.
5. `cii-workspace-method-c-exports.js`: `methodCJsonExport`, `methodCCsvExport`, `methodCSvgExport` contain complete candidate/alternate/conflict/element/segment inventory. Exports fail closed when current original hashes, registration, tolerance or projection differ from the source snapshot. CSV strings are protected against formula execution; signed numerical residuals remain numeric.
6. `cii-workspace-method-c-ui.js` and CSS: `mountMethodC(container, {source,target})` creates the full read-only DOM review UI. Alternatively the user may upload original CII files through the provided SOURCE/TARGET file inputs. The UI never invokes Writer2. `mountMethodC` returns `{state,refresh,select,setFiles,dispose}`; accepted graphs in `setFiles` must originate from validated Workspace original bytes at the separately approved WP6 integration seam.
